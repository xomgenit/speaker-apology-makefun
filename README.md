One-line entry for make.fun's "Sorry, I Heard That Wrong" bounty: the funniest
one-line apology a smart speaker gives after mishearing its owner (max 140
characters).

## Entry

> Sorry, I heard 'play my sad songs' as 'order 40 pizzas.' In my defense, both fix the same problem.

## Run

```sh
node main.ts
```

Writes the entry line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `./out` when
unset), with no trailing newline.
